# End-to-End Implementation Guide

This guide details the construction of a complete project scaffolding and patching workflow using XRU 2.0.

---

## Objective

We will build an automation script named `setup.xru` that:
1. Accepts typed CLI arguments (`projectName`, `environment`, `port`).
2. Validates parameters using an `@map` interface schema.
3. Provisions project directory hierarchies safely.
4. Generates and surgically mutates a `package.json` file.
5. Injects code into a TypeScript source file (`src/index.ts`) using semantic matching.
6. Dispatches recursive cleanup rules via `dispatch`.

---

## 1. Project Layout

Create an isolated directory structure:

```text
workspace/
├── _mod.xru
└── setup.xru
```

### The `_mod.xru` Manifest:
```xru
map meta {
    name: "project-scaffolder",
    version: "2.0.0"
}
```

---

## 2. Complete Script: `setup.xru`

```xru
use std
use fs
use json

// --------------------------------------------------------------------------
// 1. CLI ARGUMENT DECLARATIONS
// --------------------------------------------------------------------------
arg projectName: string             // Required parameter (--projectName=...)
arg env: string = "development"     // Optional with default
arg port: number = 3000             // Optional typed number

// --------------------------------------------------------------------------
// 2. TYPE CONTRACTS & VALIDATION
// --------------------------------------------------------------------------
interface BuildConfig @map {
    name string
    targetEnv "development" or "staging" or "production"
    listenPort number
    isProduction bool
}

const config: BuildConfig = @map {
    name: projectName,
    targetEnv: env,
    listenPort: port,
    isProduction: env == "production"
}

std.info("Configuring project '$f{config.name}' under '$f{config.targetEnv}' (port $f{config.listenPort})...")

// --------------------------------------------------------------------------
// 3. TARGET DIRECTORY PROVISIONING
// --------------------------------------------------------------------------
const targetDir = "./output/$f{projectName}"
fs.ensureDir("$f{targetDir}/src")

// --------------------------------------------------------------------------
// 4. SURGICAL JSON TRANSFORMATION
// --------------------------------------------------------------------------
file "$f{targetDir}/package.json", (doc, err) -> {
    if err != nil {
        doc.setContent(`{
  "name": "placeholder",
  "version": "1.0.0",
  "scripts": {
    "dev": "node dist/index.js"
  }
}`)
    }

    doc.setJson("name", config.name)
    doc.setJson("version", "1.0.0")
    doc.setJson("scripts.start", "node dist/index.js")
    doc.setJson("config.port", config.listenPort)
    doc.setJson("config.production", config.isProduction)

    std.success("package.json successfully configured.")
}

// --------------------------------------------------------------------------
// 5. TYPESCRIPT CODE INJECTION
// --------------------------------------------------------------------------
file "$f{targetDir}/src/index.ts", (doc) -> {
    doc.setContent(`
import express from 'express';

const app = express();
const PORT = 8080;

app.get('/health', (req, res) => {
    res.json({ status: "ok" });
});

app.listen(PORT, () => {
    console.log("Server listening...");
});
`)

    doc.replaceFuzzy("const PORT = 8080;", "const PORT = $f{config.listenPort};")
    doc.prepend("// Autogenerated by XRU at build-time\n")

    std.success("src/index.ts generated and patched.")
}

// --------------------------------------------------------------------------
// 6. SUB-ORCHESTRATION VIA DISPATCH
// --------------------------------------------------------------------------
std.info("Dispatching modular sub-rules...")
dispatch targetDir, "*.rules.xru"

std.success("Project '$f{projectName}' provisioned and ready.")
```

---

## 3. Running the Routine

Execute the script using the XRU CLI:

```bash
xru run setup.xru --projectName=MicroserviceCore --port=4000 --env=production
```

### Terminal Output:
```text
[INFO] Configuring project 'MicroserviceCore' under 'production' (port 4000)...
[SUCCESS] package.json successfully configured.
[SUCCESS] src/index.ts generated and patched.
[INFO] Dispatching modular sub-rules...
[SUCCESS] Project 'MicroserviceCore' provisioned and ready.
```
