# XyPriss Rule Unit (XRU) Syntax Highlighting

This extension provides syntax highlighting for **XyPriss Rule Unit (.xru)** transformation files.

## Features

- **Directives**: Highlights `#BEGIN`, `#CREATE`, `#END`, `@*INJECT`, and `@END`.
- **Patch Operations**: Highlights `&merge`, `&add`, `&rm`, `&rp-k`, `&rp-v`, `&append`, and `&regex`.
- **Values**: Full support for strings, numbers, booleans, and objects.
- **Comments**: Supports `//` line comments.
